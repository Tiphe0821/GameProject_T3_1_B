제작 시스템 설명서
작성일: 2026-11-23 / 대상 스크립트: CraftingStation, PlayerCrafting

====================================================
1. 한눈에 보기
====================================================

- 작업대는 E키로 상호작용한다.
- CraftingStation은 제작대에 붙인다.
- PlayerCrafting은 플레이어(주인공)에게 추가한다.


====================================================
2. 스크립트 구성
====================================================

[CraftingStation]
  붙이는 곳 : 제작대 오브젝트
  역할      : 레시피(재료, 결과물)를 보관하고, 제작을 실행한다 (TryCraft)

[PlayerCrafting]
  붙이는 곳 : 플레이어(주인공)
  역할      : E키 입력을 감지해서 가장 가까운 제작대의 TryCraft를 호출한다

[PlayerItemInteraction] (한 줄 추가)
  붙이는 곳 : 플레이어(주인공)
  역할      : 제작대 근처에서는 E키로 들고 있는 아이템이 같이 사용되지 않게 막는다


====================================================
3. 제작 규칙
====================================================

1. 제작을 할 시 재료 아이템을 인벤토리에서 제거한다.
2. 수량이 부족할 경우 제작이 취소된다. (아이템은 제거하지 않는다)
3. 수량이 충분할 경우 1번을 실행한 뒤 인벤토리에 결과 아이템을 추가한다.

추가로 지켜지는 안전 장치는 다음과 같다.

- 같은 재료가 여러 줄에 적혀 있어도 합산해서 확인한다.
- 결과물이 ItemDatabase에 등록되어 있지 않으면 제작을 취소한다.
  (재료만 사라지는 일을 막는다)
- 결과물 추가에 실패하면 제거했던 재료를 돌려준다.

[제작이 실행되는 순서 (CraftingStation.TryCraft)]

1. 결과물 id와 수량이 설정되어 있는지 확인한다.
2. 결과물이 ItemDatabase에 등록되어 있는지 확인한다.
3. 재료를 합산해서 필요한 개수를 계산한다.
4. 재료가 하나라도 부족하면 취소한다. (여기까지는 인벤토리가 바뀌지 않는다)
5. 재료를 인벤토리에서 제거한다.
6. 결과물을 인벤토리에 추가한다. 실패하면 재료를 돌려준다.


====================================================
4. 사용 방법
====================================================

1. 플레이어(주인공) 오브젝트에 PlayerCrafting을 추가한다.
2. 제작대로 쓸 오브젝트를 만든다. 반드시 Collider가 있어야 한다.
3. 제작대 오브젝트에 CraftingStation을 추가한다.
4. 제작대의 인스펙터에서 레시피를 입력한다.
5. 재료와 결과물 아이템이 모두 ItemDatabase에 등록되어 있는지 확인한다.
6. 플레이 모드에서 재료를 줍고, 제작대 가까이에서 E키를 누른다.
   결과는 Console 창에 표시된다.

[제작대 인스펙터 입력 항목]

- Ingredients    : 재료 목록. + 버튼으로 칸을 늘리고, 칸마다 Item Id와 Amount를 입력한다
- Result Item Id : 제작되어 나오는 아이템의 id
- Result Amount  : 한 번 제작할 때 나오는 개수

레시피 예시 (id는 예시이므로 실제 아이템 id로 바꿀 것):
재료 iron 2개와 wood 1개를 넣으면 결과물 tool 1개가 나온다.


====================================================
5. E키 우선순위
====================================================

같은 E키를 여러 스크립트가 쓰기 때문에 겹치지 않도록 정리되어 있다.

1. 근처에 줍을 아이템이나 문이 있으면 PlayerPickup이 먼저 동작한다.
2. 그다음 제작대가 있으면 PlayerCrafting이 제작한다.
3. 근처에 아무것도 없으면 PlayerItemInteraction이 핫바에서 들고 있는 아이템을 사용한다.

주의: 제작대 근처에 줍을 아이템이나 문이 있으면 제작이 되지 않는다.
먼저 아이템을 줍거나 그 자리에서 벗어나야 한다.

세 스크립트(PlayerPickup, PlayerCrafting, PlayerItemInteraction)의
detectionRadius는 같은 값(기본 2)으로 맞춰야 한다.
값이 다르면 서로 겹치거나 둘 다 동작하지 않는 구간이 생긴다.


====================================================
6. 수정 가이드
====================================================

[제작 키 바꾸기]
  PlayerCrafting의 Update에서 keyboard.eKey를 다른 키로 바꾼다.
  PlayerItemInteraction, PlayerPickup도 같은 키를 쓰므로 겹치는지 함께 확인한다.

[제작 가능 거리 바꾸기]
  PlayerCrafting의 detectionRadius. 다른 두 스크립트와 같은 값으로 맞춘다.

[레시피 바꾸기]
  코드 수정 없이 제작대의 인스펙터에서 바꾼다.

[제작대 추가하기]
  제작대 오브젝트를 복제하고 레시피만 바꾼다.

[한 제작대에서 레시피 여러 개 쓰기]
  지금은 제작대 하나에 레시피 하나다.
  필요하면 CraftingStation에 레시피 목록과 선택 기능을 추가해야 한다.

[성공, 실패를 화면에 표시하기]
  CraftingStation.TryCraft 안의 Debug.Log 자리에서 UI 함수를 호출한다.
  TryCraft는 성공하면 true, 실패하면 false를 돌려준다.

[제작창 UI의 버튼으로 제작하기]
  버튼에서 해당 제작대의 TryCraft()를 호출하면 된다.

[제작 시간이나 애니메이션 넣기]
  TryCraft를 부르는 부분을 코루틴으로 바꾼다.
  PlayerPickup의 PickupAnimation을 참고한다.

[제작대 감지 방식 바꾸기]
  PlayerCrafting의 OverlapSphere 부분.


====================================================
7. 문제 해결
====================================================

[증상] E를 눌러도 아무 반응이 없다
  -> PlayerCrafting이 플레이어에 붙어 있는지, 제작대에 Collider가 있는지,
     거리 안에 있는지, 근처에 줍을 아이템이나 문이 없는지 확인한다.

[증상] Console에 "결과물이 ItemDatabase에 등록되어 있지 않습니다"
  -> 결과물 아이템을 Resources의 ItemDatabase에 등록한다.

[증상] "재료 부족"이 뜨는데 재료가 있다
  -> 인스펙터의 Item Id가 실제 아이템 id와 철자, 대소문자까지 같은지 확인한다.

[증상] 컴파일 오류: CraftingStation을 찾을 수 없다
  -> CraftingStation.cs 파일을 만들었는지 확인한다.
     PlayerItemInteraction이 이 클래스를 참조한다.

[증상] 컴포넌트로 붙일 수 없다
  -> 파일 이름과 클래스 이름이 같은지 확인한다.

[증상] 제작 후 핫바 칸이 바뀐다
  -> 새 아이템은 핫바의 빈 칸에 자동으로 들어가고,
     재료를 다 쓰면 그 칸이 비는 것이 정상 동작이다.


====================================================
8. 현재 없는 기능
====================================================

- 제작창 UI와 화면 안내 문구 (결과는 Console에만 표시된다)
- 한 제작대에서 레시피를 골라 쓰는 기능
- 제작 시간과 제작 중 이동 제한
